# Internal-use and data-handling notice

This repository is prepared for authorized research handover and expert review. It is not approved for public distribution.

It includes archived third-party documents, exact source quotations, model-generated research artifacts, and country-assessment material. Access, retention, reuse, and onward sharing must follow the applicable Red Cross data-protection, information-management, copyright, and research-governance rules.

No credentials are intentionally stored here. Keep API keys and service configuration only in an untracked `.env` file. Before making the GitHub repository public, publishing a release, or sharing outside the authorized group:

1. perform a copyright and data-protection review of `data/final_assessment/source_archive/`;
2. review evidence quotations and assessment content for disclosure risk;
3. run a fresh secret scan and inspect Git history, not only the working tree;
4. confirm the approved authorship, license, citation, and retention policy.
