# Evaluation archive

This directory contains saved research evaluations. These files report results;
they are not runtime dependencies of the production pipeline.

- `traceability/`: strict/lenient quotation audits and rejected-row analysis;
- `evidence_quality/`: evidence-strength coding and summaries;
- `prompt_sensitivity/`: retained prompt sensitivity outputs;
- `negative_controls/`: negative-source designs, manifests, and outcomes;
- `expert_review/`: original expert-evaluation response export and its notes.

Do not recompute or overwrite reported results in place. New analyses should use
a new filename and record the source artefact hashes and analysis method.
