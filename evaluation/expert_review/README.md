# Expert review

`expert_evaluation_responses.xlsx` is the original Microsoft Forms Excel export
used for the retained expert-rating figure. It contains one completed anonymous
response and is preserved byte-for-byte.

- Original filename: `Expert evaluation of LLM-assisted DEMA assessments(1-1).xlsx`
- Size: 38,282 bytes
- SHA-256: `98d1f663de6e5a02bff60e78f2a2c762c1baa574ddf1515c7c5100362eeeb558`

The export contains eight repeated assessment blocks with nine Likert ratings
and one categorical diagnostic item per block. Microsoft Forms section titles
are not retained in the Excel columns. The figure generator therefore labels
the rows in the standard DEMA framework order; this assumption is stated in the
figure note.

Review authorization and disclosure risk before sharing the workbook outside
the approved research group, even though the retained response is anonymous.
