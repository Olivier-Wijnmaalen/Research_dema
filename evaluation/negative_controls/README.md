# Negative-control evaluations

The authoritative completed stress test is the blinded **60 genuine + 155 synthetic control** run. Its run manifest, summary, detailed results, and matched comparisons are retained here.

`historical_extreme_2_genuine_design.md` describes an earlier two-genuine-record evidence-starvation design. It must not be used to describe the final 60-strong run.

The full stress-test phase changes are not a causal estimate of synthetic-control effects because the test also removed most genuine baseline evidence. The matched A.1.2 and B.1.3e comparisons provide the direct paired checks retained by the project.
